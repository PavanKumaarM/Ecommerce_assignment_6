# Ecommerce_assignment_6
1. Features included
- Fetch products from a fake e-commerce API.
- Display products as cards in a grid.
- Pagination with Previous and Next buttons.
- Search products by typing the complete product title. Partial words will not trigger results.
- Show Product Not Found when no exact title matches.
- Show a loading message while fetching data.
- Display custom error pages for 404, 500, and other failed API requests.
- Use CSS relative, absolute, and fixed positioning.
